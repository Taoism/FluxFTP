# FluxFTP 0.147.2

## Keyboard shortcuts

- Open Options with F6 from anywhere in the main window. The Options toolbar
  tooltip now shows the shortcut.

## Workspace behavior

- Preserve pane order when both panes use the same mode, including when cloning
  a workspace with two local folders.

See the release assets for Windows, Ubuntu, and Debian packages and SHA-256
checksums.
