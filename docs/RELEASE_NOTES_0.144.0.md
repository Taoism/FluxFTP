# FluxFTP 0.144.0

## Layout and workspace

- Add layout presets and customization under Tools → Layout, including popup menu designers.
- Apply the selected icon set to layout commands and popup menu actions.
- Remember resized dock panels, floating windows, and workspace placement between launches.

## Transfers and site browsing

- Show progress on each file in folder transfers.
- Support Ctrl-click and Shift-click multi-selection in file panes.
- Detect directory symbolic links on FTP and SFTP sites so they can be opened for browsing.
- Report folder totals in megabytes and add a combined series summary that ignores `SxxExx` episode markers.

See the release assets for Windows, Ubuntu and Debian packages and SHA-256
checksums.
