Main window and workspaces

The workspace shows local and remote file panes. Each pane can have multiple tabs, so you can keep several folders or connections open. The transfer queue lists work waiting to run and its progress; the log provides connection and transfer details.

Toolbar

Toolbar buttons provide shortcuts for common navigation, queue, pane, log, and FTP terminal actions. Hover over a button to see its tooltip. Available actions depend on the current connection and selection.

Queue and log

Use the queue controls to start, pause scheduling, stop, or manage selected jobs. Queue recovery can restore unfinished work after a restart. Pausing the queue may wait for the current file; some operations such as FXP and cloud-managed copies cannot pause mid-operation.

Use the View menu to show or hide workspace panels. The Options pages control appearance, confirmations, file handling, connections, and notifications.
