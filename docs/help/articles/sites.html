Site Manager and connections

Open Tools → Site Manager to create, organize, edit, import, and export saved sites. Groups use folder icons; protocol and cloud entries have distinct icons. A saved profile keeps connection settings and authentication material in the local encrypted credential vault.

Protocols

  • FTP: unencrypted; credentials and data may be exposed on the network.
  • FTPS: FTP protected with TLS. Select explicit or implicit mode as required by the server.
  • SFTP: file transfer over SSH, normally on port 22.
  • SCP: legacy SCP payload transfer over verified SSH. Browsing and metadata still require SFTP; the server needs an SCP program and compatible shell.
  • Cloud: providers configured through the installed rclone integration. See Cloud storage.

Site properties include connection, proxy, data connection, retry, transfer, and advanced options. Use Tools → Connection Diagnostics to test DNS, connection, authentication, and directory/data access. These checks do not upload a file or prove write permission.
