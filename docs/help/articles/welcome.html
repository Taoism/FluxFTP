Welcome to FluxFTP

FluxFTP is a Windows file transfer client for FTP, FTPS, SFTP, SCP, and supported cloud storage. It provides a two-pane workspace, saved sites, a recoverable transfer queue, synchronization, and deployment tools.

Choose a topic from the index or search for a feature. The same articles are included in the desktop app's Help → Help Index (F1) and in this online Help Center.

Security basics

FTP does not encrypt credentials or file data. Prefer FTPS or SFTP when the server supports them. Review certificate and SSH host-key prompts carefully before trusting a server.
