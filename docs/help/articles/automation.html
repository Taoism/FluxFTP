Watch folders and automation

Watch-and-upload polls selected local folders while FluxFTP is running. A file must remain unchanged across its settle interval before it is queued. This cannot guarantee that another application has closed the file. Configure exclusions and conflict behavior, then try the rule with a disposable destination.

Scheduled automation and scripts can run supported FluxFTP tasks. Review command templates and script steps before running them. Scheduled work depends on the application or configured automation runner being available at the scheduled time.

Synchronization and deployment profiles are separate tools with reviewable previews. See Synchronize folders and Deployments and rollback.
