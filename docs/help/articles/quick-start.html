Quick start

  1. Open Tools → Site Manager and create a site.
  2. Choose the server protocol and enter its host, port, and authentication details. Save the profile.
  3. Select the site and connect. Review any certificate or SSH host-key trust prompt.
  4. Browse folders in the remote pane. Browse local folders in the other pane.
  5. Select files or folders and add them to the queue, then start the queue.

FTP commonly uses port 21; implicit FTPS commonly uses 990; SFTP commonly uses 22. Confirm the required port and security mode with your server administrator. SCP shares SSH authentication, but file browsing uses SFTP.

For safe first use, try a small file in a test folder. Read Certificates, SSH trust, and diagnostics if a connection asks you to verify the server.
