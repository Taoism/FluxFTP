Certificates, SSH trust, and diagnostics

FTPS uses a TLS certificate; SFTP and SCP use an SSH host key. Verify the server identity through a trusted channel before accepting a new certificate or fingerprint. FluxFTP records explicit trust decisions for the applicable site or host.

The Certification Checker reports certificate validity and fingerprints, negotiated security, and CA/hostname versus saved-pin trust. For SSH it reports the verified host-key fingerprint. It is a diagnostic report, not an organizational certificate audit; revocation status may not be checked.

Connection Diagnostics checks name resolution, TCP/proxy setup, login, and directory/data access. It does not perform an upload or prove write access. Exported reports redact known credentials, but can contain host names and paths.
