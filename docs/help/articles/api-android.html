JSON API and Android companion

The optional local JSON API is available while FluxFTP is running. It binds only to 127.0.0.1:8765 and requires a bearer token shown in Tools → JSON API Access. The token can manage the queue and create transfers, so treat it like a password.

The API supports queue status, transfer listing and creation, queue play/pause/stop, and cancellation. Saved-site credentials are never returned. Transfer endpoints refer to desktop paths and saved sites.

The Android companion adapts its layout for phones and tablets. It uses the desktop API to view and manage transfers; files still move between the desktop's local paths and configured sites. Keep the API on loopback and connect through an authenticated port forward or private VPN. Never expose port 8765 directly to a network. Emulator setup is documented in the Android build guide.
