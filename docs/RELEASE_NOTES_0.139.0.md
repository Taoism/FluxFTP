# FluxFTP 0.139.0

## Highlights

- Added right-click **Hide panel** actions to dock panel titles and tabs.
- Added **Edit site…** to saved sites in pane dropdown menus.
- Kept workspace tabs beside the single Workspaces heading, with a plus button
  for new workspaces and a close button on the active tab when multiple tabs are
  open. Workspace names stay generic instead of changing to connected site names.
- Added a divider between duplicated workspace tabs and preserved their grouping
  across restarts.
- Added double-click column sizing and made Quick Connect fields start blank.

See the release assets for Windows, Ubuntu and Debian packages and SHA-256
checksums.
