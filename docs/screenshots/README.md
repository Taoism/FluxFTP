# Screenshot provenance

`main-interface.png` and `main-interface-large-text.png` were captured from the
unmodified `FluxFTP.exe` extracted from the published
`FluxFTP-0.113.0-windows-x64.zip` release. They are native window captures, not
mockups or source-rendered previews.

The executable's SHA-256 is recorded below after verification against the packaged
copy:

```text
2c343782539e07168c70aa156676a57aa2c81bbb1ab1086898158305a6d953f4
```

The captures use its built-in `--smoke-test --screenshot` mode, which creates
temporary settings and exits after saving `preview.png`. No real account is
connected. The second capture sets `QT_SCALE_FACTOR=1.5` before launch; the first
uses the normal display scale. No image content was altered after capture.

The other images are earlier feature-dialog previews using synthetic data.
