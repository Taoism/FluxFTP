# Roadmap

The following are planned improvements, not promises of a release date. Existing
search, editing, notifications and workspace persistence will be extended rather
than replaced.

- [ ] Command palette for commands, sites, folders and profiles.
- [ ] Remote search filters for filename, size and date, with download/navigation actions.
- [ ] Optional upload-on-save for remote editing, conflict detection and backups.
- [ ] Transfer preflight for available space, destination access and path conflicts.
- [ ] Reusable queue recipes with endpoints, filters and verification policies.
- [ ] Actionable Windows completion/failure notifications.
- [ ] Connection health dashboard for latency, throughput, retries and failures.
- [ ] GitLab pipeline-artifact deployments with commit/pipeline provenance.
- [ ] Deployment revision comparison and text diffs.
- [ ] Workspace preset quick switcher.
- [ ] GitHub repository publication and versioned downloadable releases with checksums.
- [ ] Repeatable public release builds, complete dependency notices and signing.
- [ ] Further real-network active FTP and production protected-FXP interoperability testing.

Recently implemented in 0.113.0: unified bandwidth management, verification-report
exports and deployment profiles with guarded rollback. Version 0.112.0 added
connection diagnostics, enhanced folder synchronization and watch-and-upload folders.
