# FluxFTP 0.138.0

## Highlights

- Added GitHub release update checks for supported Windows, Ubuntu, and Debian installations. FluxFTP verifies the package checksum and asks before installing an update.
- Added a General option to check for new FluxFTP releases on GitHub at startup.
- Added a movable, nested Tools panel and independent icons, address bar, and filter toolbars in each file pane.
- Added an FTP Rush-style layout preset with the two-pane workspace above a bottom tab area for the transfer queue and logs. Panel positions are saved when FluxFTP exits.
- Double-clicking the divider between the two file panes restores equal pane widths.
- Fixed the local Windows packaging scripts so they can use the validated runtime from a separate build environment and correctly merge bundled license files.

See the release assets for platform downloads and SHA-256 checksums.
